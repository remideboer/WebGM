# WebGM

WebGM is an attempt to gather together tools and random generators for the purposes of:
 1) Emulating a Game Master for solo play of "tabletop" RPGs
 2) Creative inspiration, particularly for writing or storytelling
 3) Procedural generation of content ideas, particularly for role-playing games.
 
While there are other attempts to create such a tool available on the internet, to my knowledge none are open-source, and most are maintained by a single coder. WebGM attempts to rectify this problem, allowing as many people as are interested to contribute to the development of the project, as well as allowing free use for all. It is hoped that this will result in a higher-quality program incorporating the best of what the solo rpg-playing community is capable of.
 
All content produced by the generators and/or tools of WebGM is available for any and all use, including commercially and without attribution. The source code of WebGM is available under the GNU General Public License, version 3. Of course, the creators would enjoy knowing about anything you create with the help of WebGM.

All content within WebGM (that is to say, the random generators, the lists used for those generators, and the game mechanics implied by the structure of the tool) is used in accordance with any licenses concerning it, or has been changed to the extent where it would be considered a transformative work under the laws of fair use.

## Features

### Decision Making
- **Mythic GM 2e Decision System**: Ask yes/no questions with adjustable odds (Certain, Nearly Certain, Very Likely, Likely, 50/50, Unlikely, Very Unlikely, Nearly Impossible, Impossible) and Chaos Factor (1-9). Results include: Yes, No, Yes, and..., No, and... with color-coded display cards.

### Card Generation
- **Poker Cards**: Draw random playing cards
- **Tarot Cards**: Draw random tarot cards
- **Glyphs**: Generate random glyph images (220+ available)

### Dice Rolling
- **Custom Dice**: Roll any number of dice with any number of sides
- **Fate/Fudge Dice**: Roll Fudge/Fate dice for narrative gaming

### Damage & Danger
- **Damage Generator**: Generate damage results with adjustable danger level (0-10)

### World & Scenario Elements
- **Genre**: Generate random genres
- **Event**: Generate random events
- **Setting**: Generate random settings
- **Item**: Generate random items
- **Quest**: Generate random quests
- **Color**: Generate random colors with WCAG-compliant contrast text
- **Animal**: Generate random animals
- **Sense Snippet**: Generate sensory descriptions

### Character Elements
- **Name**: Generate random names
- **Character**: Generate random character descriptions
- **Characteristic**: Generate random characteristics
- **Role**: Generate random roles
- **Motivation**: Generate random motivations
- **Quirk**: Generate random quirks
- **Friendliness**: Determine NPC friendliness levels

### Creature & Magical Elements
- **Creature**: Generate random creatures
- **Magical Effects**: Generate random magical effects

### User Interface
- **Card-based Display**: All generated content appears in color-coded cards with chronological ordering
- **Collapsible Control Cards**: Organize controls into collapsible groups for better space management
- **Copy to Clipboard**: Copy all generated text in chronological order
- **Message Notifications**: Non-intrusive notifications for user feedback
- **Responsive Design**: Clean, ergonomic layout optimized for readability
